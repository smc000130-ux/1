📂 여기에 놓아 파일 불러오기

cycles_data.json 파일을 불러오세요

상단 [📂 파일 불러오기] 버튼을 누르거나, 화면 어디든 파일을 끌어다 놓으면 됩니다.

6종류 파일 중 하나를 고르면 사이클마다 독립된 차트 카드가 세로로 생성되고, 다른 파일을 고르면 즉시 교체됩니다.

  {
    "cycle_id": 1,
    "title": "[메인 상승장 #1] 1971.02.05 ~ 1973.01.11 (...)",
    "start_date": "1971-02-05",
    "end_date": "1973-01-11",
    "tickers": ["SP500", "NASDAQ"],
    "data": [
      {"date": "1971-02-05", "SP500": 0.0, "SP500_price": 96.83,
       "NASDAQ": 0.0, "NASDAQ_price": 100.0}
    ]
  }
